# Pacote Apps Script do DED

Esta pasta é a versão HTML Service da mesma interface do DED. `Index.html` e `ConsolidatedCore.gs` são gerados por `npm run build`; não editar esses dois arquivos manualmente. `Code.gs` contém o backend e `appsscript.json` o manifesto.

Instalação, abas/colunas, propriedades, autorização, atualizações e checklist estão no [plano de implementação](../docs/PLANO_TRANSICAO_GOOGLE_APPS_SCRIPT_CONSOLIDADOS.md).

Nenhum deploy é automático. Configurar uma planilha privada por escola e allowlist de usuários institucionais. Esta etapa persiste os Consolidados; as bases de Lançamentos do Professor continuam no fluxo local existente.
